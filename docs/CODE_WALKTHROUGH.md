## 5. Reading tips / 阅读提示

- Start with `SearchPipeline.search` and `train`; most other modules exist to make their inputs verifiable.
- The controller imports no ML library, so its tests use fake stages; within `execution/`, torch is imported only by `world.py`, `stages.py`, `probe.py` (calibration worker) and `exporter.py`.
- Some package `__init__.py` docstrings predate the implementation (for example `training/__init__.py` still says no trainer is implemented);
  the module docstrings next to the code are the accurate ones. This is noted, not changed, because this branch edits documentation only.
- Tests are under `tests/`; `tests/test_scaffold.py` enforces the layering between packages.
