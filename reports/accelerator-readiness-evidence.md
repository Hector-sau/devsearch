## 0. Read this first / 先读这里

**This is engineering evidence on CPU in one Linux container. Most of it uses synthetic and diagnostic data; the rest uses one real public corpus with questions that an agent workflow wrote and an independent agent reviewed. It is not accelerator readiness and not a reranker result.** There is no MPS or CUDA run, no pinned real MiniLM or tokenizer (the real-corpus steps use an unpinned BERT-uncased vocabulary stand-in, so everything derived from it is conditional), no human review and no judged candidate-review bank. The phrase "only the GPU is left" is **false**: the open items in section 4 include assets, human review of the labels, the candidate judgments, target-machine lock installation and CI, none of which a GPU provides. Estimates (section 3) are kept apart from measurements. The only ranking numbers quoted are the BM25-only figures on 202 synthetic validation questions (2.8); they say nothing about a reranker or about real user queries. Every ranking metric inside `rehearsal/` comes from a planted synthetic cue and is not quoted.

**这是在单个 Linux 容器 CPU 上的工程证据。大部分使用合成与诊断数据；其余使用一个真实公开语料，问题由 Agent 工作流撰写、并由独立 Agent 审查。它不是加速器就绪，也不是重排结果。**尚无 MPS／CUDA 运行、固定的真实 MiniLM 与分词器（真实语料步骤使用未固定的 BERT-uncased 词表替代，因此其衍生结果都是有条件的）、真人审查或已判定的候选审查库。“只差 GPU”的说法**不成立**：第 4 节的未决项还包括资产、标注的真人复核、候选判定、目标机依赖锁安装和 CI，GPU 都不能提供。估算（第 3 节）与实测分开。唯一引用的排序数字是 202 个合成验证问题上仅 BM25 的结果（2.8），它们不说明重排，也不代表真实用户问题；`rehearsal/` 内的排序指标来自合成的植入线索，此处不引用。
